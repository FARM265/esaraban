# ติดตั้งบน Google Cloud (เครื่องเช่าที่กรุงเทพ)

เช่าเครื่อง (VM) 1 เครื่องบน Google Cloud ภูมิภาคกรุงเทพ ระบบรันเหมือนบนคอมในสำนักงานทุกอย่าง
ข้อมูลอยู่ในประเทศไทย ไม่ต้องเปิดคอมทิ้งไว้ ทำผ่านหน้าเว็บทั้งหมด ไม่ต้องลงโปรแกรมเพิ่ม

ใช้เวลาประมาณ 1 ชั่วโมง (รอ build ประมาณ 15 นาที)

## ขั้นที่ 1: สมัครและตั้งงบประมาณ

1. เข้า https://console.cloud.google.com ด้วยบัญชี Google ของหน่วยงาน กด **Start free / เริ่มใช้งาน** แล้วผูกบัตรหรือวิธีชำระเงิน
2. สร้างโปรเจกต์ใหม่ชื่อ `esaraban`
3. **ตั้งงบเตือน** (กันค่าใช้จ่ายเกิน): เมนู **Billing > Budgets & alerts > Create budget** ใส่จำนวนต่อเดือนที่รับได้
   ระบบจะส่งอีเมลเตือนเมื่อใช้ถึง 50% 90% 100%

## ขั้นที่ 2: สร้างเครื่อง (VM)

เมนู **Compute Engine > VM instances** (ครั้งแรกกด Enable API แล้วรอสักครู่) กด **Create instance**

| ช่อง | เลือก |
|---|---|
| Name | `esaraban` |
| Region | **asia-southeast3 (Bangkok)** |
| Machine type | **E2 > e2-medium** (2 vCPU, 4 GB) |
| OS and storage > Change | **Ubuntu 24.04 LTS (x86/64)**, ขนาด **50 GB**, Balanced persistent disk |
| Networking > Firewall | ติ๊ก **Allow HTTP traffic** และ **Allow HTTPS traffic** |

ด้านขวาของหน้าจอแสดงราคาประมาณต่อเดือน ตรวจก่อนกด **Create**

**ล็อก IP ไม่ให้เปลี่ยน:** เมนู **VPC network > IP addresses** หา IP ของเครื่อง `esaraban`
กดจุด 3 จุด > **Promote to static IP address** ตั้งชื่อ `esaraban-ip`

## ขั้นที่ 3: เตรียมไฟล์บนคอมของท่าน

ใน PowerShell ที่ `C:\Projects\esaraban`
```
powershell -ExecutionPolicy Bypass -File scripts\make-upload-zip.ps1
```
ได้ไฟล์ `esaraban-upload.zip` ที่หน้า Desktop (ไม่มีรหัสลับและข้อมูลเอกสารอยู่ข้างใน)

## ขั้นที่ 4: อัปโหลดและติดตั้ง

1. หน้า **VM instances** กดปุ่ม **SSH** ที่แถว `esaraban` จะได้หน้าต่างพื้นดำ (กด Authorize ถ้าถาม)
2. กดไอคอน **Upload file** มุมขวาบนของหน้าต่าง เลือก `esaraban-upload.zip` จาก Desktop รอจนขึ้นว่าเสร็จ
3. คัดลอกคำสั่งนี้ไปวางในหน้าต่างพื้นดำ แล้วกด Enter
   ```
   python3 -m zipfile -e esaraban-upload.zip . && sed -i 's/\r$//' esaraban/scripts/install-server.sh && sudo bash esaraban/scripts/install-server.sh
   ```
4. ตอบคำถาม
   - รหัสหนังสือของหน่วยงาน (กด Enter ข้ามได้)
   - รอ build ประมาณ 10–15 นาที
   - สร้างผู้ดูแลระบบคนแรก: ชื่อผู้ใช้ อีเมล รหัสผ่าน (พิมพ์รหัสผ่านแล้วจะไม่แสดงบนจอ เป็นเรื่องปกติ)
5. **สำคัญที่สุด: เก็บค่าลับ** กดไอคอน **Download file** ใส่ที่อยู่ไฟล์ที่สคริปต์แสดง
   (`/home/ชื่อผู้ใช้/esaraban-secrets-KEEP-SAFE.txt`) เก็บไฟล์ไว้ในที่ปลอดภัย เช่น แฟลชไดรฟ์ในตู้นิรภัย
   **ถ้าไฟล์นี้หาย ไฟล์เอกสารในชุดสำรองจะเปิดไม่ได้อีกเลย** จากนั้นพิมพ์ในหน้าต่างพื้นดำ
   ```
   rm ~/esaraban-secrets-KEEP-SAFE.txt
   ```

## ขั้นที่ 5: เข้าใช้งาน

1. เปิด `https://IP-ของเครื่อง` (สคริปต์แสดงให้) ครั้งแรกเบราว์เซอร์เตือนเรื่องใบรับรอง กด "ขั้นสูง" แล้ว "ดำเนินการต่อ"
2. เข้าสู่ระบบด้วยผู้ดูแลระบบ
3. เมนู **สถานะระบบ** ต้องผ่านทุกข้อ
4. ตั้งค่าสำนักงานตาม [คู่มือติดตั้ง](install.md) ข้อ 4 แล้วสร้างบัญชีให้เพื่อนร่วมงาน

## สำรองข้อมูล

- **อัตโนมัติทุกคืน 02:30** สคริปต์ตั้งไว้แล้ว เก็บในเครื่อง 30 วัน (`/opt/esaraban/backups`)
- **สำเนานอกเครื่อง (แนะนำ ทำครั้งเดียว):** เมนู **Compute Engine > Snapshots > Create snapshot schedule**
  ตั้งรายวัน เก็บ 14 วัน Region เดียวกัน แล้วไปที่ **Disks > esaraban > Edit** เลือก schedule นี้
  ถ้าเครื่องเสีย สร้างเครื่องใหม่จาก snapshot ได้ทันที
- เก็บไฟล์ค่าลับจากขั้นที่ 4 ข้อ 5 แยกไว้เสมอ

## ปรับปรุงเป็นรุ่นใหม่

ทำขั้นที่ 3 และขั้นที่ 4 ข้อ 1–3 ซ้ำ (คำสั่งเดิม) สคริปต์จะนำโค้ดใหม่ไปใช้โดยไม่แตะข้อมูลและรหัสลับเดิม

## แก้ปัญหา

| อาการ | ทำอย่างไร |
|---|---|
| เปิดเว็บไม่ได้ | ตรวจว่าติ๊ก Allow HTTP/HTTPS ตอนสร้างเครื่อง (แก้ได้ที่ VM > Edit > Networking) |
| สคริปต์บอกว่าระบบยังไม่พร้อม | ในหน้าต่าง SSH พิมพ์ `cd /opt/esaraban && sudo docker compose --env-file .env.docker logs web --tail 80` แล้วส่งภาพให้ผู้พัฒนา |
| IP เปลี่ยน | ทำขั้น "ล็อก IP" แล้วรันคำสั่งในขั้นที่ 4 ข้อ 3 ซ้ำ |
