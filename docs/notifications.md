# แจ้งเตือนทาง LINE และอีเมล

ระบบส่งการแจ้งเตือนออกไปนอกเว็บได้ 2 ทาง ผู้ใช้แต่ละคนเลือกเปิดเองที่เมนู **การแจ้งเตือน > รับแจ้งเตือนทางอีเมล/LINE**
(ต้องให้ผู้ดูแลระบบตั้งค่าตามคู่มือนี้ก่อน ช่องทางที่ยังไม่ได้ตั้งค่า หน้าตั้งค่าจะบอกว่ายังเปิดไม่ได้)

ระบบจะแจ้งเตือนในกรณีต่อไปนี้
- มีหนังสือเข้าใหม่ แจ้งหัวหน้ากลุ่มงานเจ้าของเรื่องและผู้บริหาร
- มีเรื่องรอพิจารณาหรือรอสั่งการ
- ได้รับมอบหมายให้ดำเนินการ
- เรื่องถูกส่งกลับแก้ไข
- เรื่องที่เสนอเสร็จสิ้น
- หนังสือออกเลขหรือลงนามแล้ว

> **ข้อมูลที่ส่งออกไป:** ข้อความผ่านเซิร์ฟเวอร์ของ LINE หรือผู้ให้บริการอีเมล จึงส่งเพียงหัวข้อ เลขหนังสือ ชื่อเรื่อง และลิงก์
> ไม่ส่งไฟล์ **หนังสือชั้นลับขึ้นไปไม่ส่งชื่อเรื่อง** แจ้งเพียงว่ามีเรื่องให้เปิดดูในระบบ
> ควรให้ผู้บังคับบัญชารับทราบก่อนเปิดใช้

## LINE (แนะนำ)

LINE Notify ปิดบริการไปแล้วตั้งแต่ 31 มีนาคม 2568 ระบบจึงใช้ **LINE Official Account (Messaging API)** แทน
ทุกคนเพิ่มเพื่อนบัญชีของสำนักงานบัญชีเดียว แล้วระบบส่งข้อความหาแต่ละคนเฉพาะเรื่องของคนนั้น

> **โควตาแผนฟรี:** บัญชี LINE OA แผนฟรีส่งข้อความแจ้งเตือนได้จำนวนจำกัดต่อเดือน (ดูจำนวนล่าสุดที่ LINE Official Account Manager
> > เมนู **ใช้งานแพ็กเกจ**) ข้อความตอบกลับตอนเชื่อมบัญชีไม่นับโควตา ถ้าโควตาหมด ระบบยังทำงานปกติ แจ้งเตือนในเว็บยังขึ้น
> แต่ LINE จะไม่ส่ง และหน้าตั้งค่าของผู้ใช้จะแสดงว่าส่งไม่สำเร็จ

### ขั้นที่ 1: สร้างบัญชี LINE Official Account

1. เข้า https://manager.line.biz เข้าสู่ระบบด้วย LINE ของผู้ดูแล กด **สร้างบัญชี LINE OA**
2. ตั้งชื่อ เช่น `E-Saraban ป.ป.ช. เชียงใหม่` ประเภทธุรกิจเลือกตามจริง กดสร้าง
3. ในหน้าจัดการบัญชี คัดลอก **Basic ID** (ขึ้นต้นด้วย `@` เช่น `@123abcde`) เก็บเป็นค่า **LINE_OA_ID**

### ขั้นที่ 2: เปิด Messaging API

1. ใน LINE OA Manager ไปที่ **ตั้งค่า > Messaging API** กด **เปิดใช้ Messaging API**
   เลือกหรือสร้าง Provider (ใช้ชื่อหน่วยงาน) แล้วกดตกลง
2. เข้า https://developers.line.biz/console/ เลือก Provider แล้วเลือก channel ของบัญชีนี้
3. แท็บ **Basic settings** คัดลอก **Channel secret** เก็บเป็น **LINE_CHANNEL_SECRET**
4. แท็บ **Messaging API** เลื่อนลงล่างสุด ที่ **Channel access token (long-lived)** กด **Issue**
   คัดลอกเก็บเป็น **LINE_CHANNEL_ACCESS_TOKEN** (ค่านี้คือกุญแจส่งข้อความ ห้ามส่งให้ใครหรือวางในแชต)

### ขั้นที่ 3: ใส่ค่าในระบบ

**บน Render:** เปิด service `esaraban` > **Environment** > **Add Environment Variable** ใส่ 3 ค่า
`LINE_OA_ID`, `LINE_CHANNEL_SECRET`, `LINE_CHANNEL_ACCESS_TOKEN` แล้วกด **Save, rebuild, and deploy**

**บนเครื่องในสำนักงาน:** เพิ่ม 3 บรรทัดนี้ในไฟล์ `.env.docker` แล้วรัน `docker compose --env-file .env.docker up -d`
```
LINE_OA_ID=@123abcde
LINE_CHANNEL_SECRET=...
LINE_CHANNEL_ACCESS_TOKEN=...
ESARABAN_SITE_URL=https://ที่อยู่ระบบ
```

### ขั้นที่ 4: ตั้ง Webhook

LINE ต้องส่งข้อความที่ผู้ใช้พิมพ์มาให้ระบบ (ใช้ตอนเชื่อมบัญชี) ระบบจึงต้องเปิดบนอินเทอร์เน็ตด้วย https
**ใช้ได้กับระบบบน Render** ถ้าเป็นเครื่องในสำนักงานที่เปิดได้เฉพาะในเครือข่าย LINE จะส่งมาไม่ถึง

1. LINE Developers Console > แท็บ **Messaging API** ช่อง **Webhook URL** กด Edit ใส่
   ```
   https://esaraban-q33a.onrender.com/notifications/line/webhook/
   ```
2. กด **Verify** ต้องขึ้น Success (ถ้าระบบหลับอยู่ อาจต้องเปิดเว็บก่อน 1 นาทีแล้วกดใหม่)
3. เปิด **Use webhook**
4. ใน LINE OA Manager > **ตั้งค่าการตอบกลับ** ปิด **ข้อความตอบกลับอัตโนมัติ** และ **ข้อความทักทาย**
   (ไม่อย่างนั้น LINE จะตอบข้อความของตัวเองซ้อนกับของระบบ)

### ขั้นที่ 5: ผู้ใช้เชื่อม LINE ของตนเอง

1. เข้าระบบ > กระดิ่ง **การแจ้งเตือน** > **รับแจ้งเตือนทางอีเมล/LINE** > กด **เชื่อม LINE**
2. สแกน QR อันแรกด้วยมือถือเพื่อเพิ่มเพื่อนบัญชีของสำนักงาน
3. สแกน QR อันที่สอง LINE จะเปิดแชตพร้อมรหัส 8 ตัว กดส่ง (รหัสใช้ได้ 10 นาที ครั้งเดียว)
4. LINE ตอบว่า "เชื่อมกับบัญชี ... แล้ว" กลับมาที่เว็บกด **ตรวจสถานะ** แล้วกด **ส่งข้อความทดสอบ**

## อีเมล

### บน Render (แผนฟรี) ใช้ Brevo

Render แผนฟรีปิดการส่งอีเมลแบบ SMTP ระบบจึงส่งผ่าน API ของ Brevo แทน (แผนฟรีส่งได้วันละ 300 ฉบับ)

1. สมัครที่ https://www.brevo.com (แผน Free)
2. เมนู **Senders, Domains & Dedicated IPs > Senders** กด **Add a sender** ใส่อีเมลของสำนักงานหรือผู้ดูแล
   แล้วกดยืนยันจากอีเมลที่ Brevo ส่งไป
3. เมนู **SMTP & API > API Keys** กด **Generate a new API key** คัดลอกเก็บไว้
4. Render > Environment เพิ่ม
   | ค่า | ใส่ |
   |---|---|
   | `NOTIFY_EMAIL_BACKEND` | `brevo` |
   | `BREVO_API_KEY` | API key จากข้อ 3 |
   | `NOTIFY_EMAIL_FROM` | อีเมลผู้ส่งที่ยืนยันแล้วในข้อ 2 |

อีเมลฉบับแรก ๆ อาจเข้ากล่องจดหมายขยะ ให้ผู้รับกด "ไม่ใช่สแปม" ครั้งหนึ่ง

### บนเครื่องในสำนักงาน ใช้ Gmail

1. บัญชี Gmail ที่จะใช้ส่งต้องเปิด **การยืนยันแบบ 2 ขั้นตอน** ก่อน
2. เข้า https://myaccount.google.com/apppasswords สร้าง **รหัสผ่านสำหรับแอป** ชื่อ `E-Saraban` ได้รหัส 16 ตัว
3. เพิ่มใน `.env.docker` แล้วรัน `docker compose --env-file .env.docker up -d`
   ```
   NOTIFY_EMAIL_BACKEND=smtp
   EMAIL_HOST_USER=อีเมล Gmail ที่ใช้ส่ง
   EMAIL_HOST_PASSWORD=รหัส 16 ตัวจากข้อ 2
   ESARABAN_SITE_URL=https://ที่อยู่ระบบ
   ```

## ปรับว่าใครได้แจ้ง "หนังสือเข้าใหม่"

ค่าเริ่มต้นแจ้งหัวหน้ากลุ่มงานเจ้าของเรื่องและผู้บริหาร เปลี่ยนได้ด้วย `ESARABAN_NOTIFY_INCOMING_ROLES`
เช่น `HEAD` (เฉพาะหัวหน้ากลุ่มงาน) หรือเว้นว่าง (ไม่แจ้ง)

## ถ้าไม่ได้รับแจ้งเตือน

- หน้า **รับแจ้งเตือนทางอีเมล/LINE** ของผู้ใช้ จะแสดงข้อความถ้าส่งครั้งล่าสุดไม่สำเร็จ พร้อมสาเหตุจากผู้ให้บริการ
- `HTTP 401` จาก LINE: Channel access token ผิดหรือถูกยกเลิก ออก token ใหม่แล้วใส่ใน Render
- `HTTP 429` จาก LINE: โควตาข้อความของเดือนนี้หมด
- ผู้ใช้บล็อกบัญชี LINE ของสำนักงาน: ให้เลิกบล็อก หรือยกเลิกการเชื่อมแล้วเชื่อมใหม่
