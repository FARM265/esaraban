# ใช้ระบบในเครือข่ายสำนักงาน (เครื่องเดียวเป็นเครื่องหลัก)

ใช้คอมพิวเตอร์ 1 เครื่องในสำนักงานเป็นเครื่องหลัก เพื่อนร่วมงานเปิดผ่านเบราว์เซอร์จากเครื่องของตัวเองในเครือข่ายเดียวกัน
ระบบไม่เปิดสู่อินเทอร์เน็ต

## เครื่องหลักควรเป็นแบบไหน

- คอมพิวเตอร์ตั้งโต๊ะที่เปิดทิ้งไว้ในสำนักงานได้ทั้งวัน (ถ้าเป็นโน้ตบุ๊กแล้วพกกลับบ้านหรือปิดฝา ระบบจะใช้ไม่ได้ทั้งสำนักงาน)
- ต่อสาย LAN ดีกว่า Wi-Fi
- ติดตั้ง Docker Desktop และระบบตาม README แล้ว

## ตั้งค่าครั้งเดียว

1. เปิด Docker Desktop ให้ขึ้น "Engine running"
   แล้วไปที่ Settings > General ติ๊ก **Start Docker Desktop when you sign in**
2. คลิกขวาที่ PowerShell เลือก **Run as administrator** แล้วรัน
   ```
   cd C:\Projects\esaraban
   powershell -ExecutionPolicy Bypass -File scripts\setup-office.ps1
   ```
3. ตอบคำถามในสคริปต์ (y/n) สคริปต์จะ
   - หา IP ของเครื่อง แล้วแก้ค่าใน `.env.docker` ให้เครื่องอื่นเข้าได้ (สำรองไฟล์เดิมเป็น `.env.docker.bak-วันเวลา`)
   - เปิด Firewall พอร์ต 80/443 เฉพาะเครือข่ายสำนักงาน
   - ตั้งไม่ให้เครื่องหลับเมื่อเสียบสายไฟ
   - ตั้งสำรองข้อมูลทุกวันเวลา 12:15 น.
   - เริ่มระบบใหม่ และแสดงที่อยู่ เช่น `https://192.168.1.50`
4. ลองเปิดที่อยู่นั้นจากเครื่องอื่นหรือมือถือที่ต่อ Wi-Fi สำนักงาน
   ครั้งแรกเบราว์เซอร์จะเตือนเรื่องใบรับรอง กด "ขั้นสูง" แล้ว "ดำเนินการต่อ"
5. ผู้ดูแลระบบสร้างบัญชีให้เพื่อนร่วมงานที่เมนู **ผู้ใช้และสิทธิ์**

## งานประจำ

| เมื่อไร | ทำอะไร |
|---|---|
| ทุกเช้า | ตรวจว่าเครื่องหลักเปิดอยู่ (Docker Desktop เปิดเองเมื่อเข้าสู่ระบบ Windows) |
| ทุกสัปดาห์ | คัดลอกโฟลเดอร์ `backups` ไปเก็บที่อื่น เช่น แฟลชไดรฟ์ที่เก็บในตู้ หรือ NAS ของสำนักงาน |
| เมื่อ IP เปลี่ยน (เพื่อนร่วมงานเข้าไม่ได้) | รัน `scripts\setup-office.ps1` อีกครั้ง แล้วแจ้งที่อยู่ใหม่ หรือขอ IP คงที่จากผู้ดูแลเครือข่าย |

**สำคัญ:** สำรองไฟล์ `.env.docker` เก็บแยกไว้ในที่ปลอดภัย ถ้าไฟล์นี้หายจะเปิดไฟล์เอกสารที่สำรองไว้ไม่ได้
ดู [การสำรองและกู้คืนข้อมูล](backup-restore.md)

## แก้ปัญหา

| อาการ | ตรวจ |
|---|---|
| เครื่องอื่นเปิดไม่ได้ (หมุนค้าง) | เครื่องหลักเปิดอยู่ไหม, IP เปลี่ยนหรือไม่ (`ipconfig`), Windows ตั้งเครือข่ายเป็น Public หรือไม่ |
| ขึ้น "Bad Request (400)" | เปิดด้วยที่อยู่ที่ไม่อยู่ในรายการ ให้รันสคริปต์ตั้งค่าใหม่ |
| เครื่องหลักเองก็เปิดไม่ได้ | เปิด Docker Desktop แล้วรัน `docker compose --env-file .env.docker up -d` |
